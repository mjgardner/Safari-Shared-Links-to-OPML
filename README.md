# Safari Shared Links to OPML

> [!NOTE]
> This project is hosted at [forgejo.phoenixtrap.com/mjg/Safari-Shared-Links-to-OPML](https://forgejo.phoenixtrap.com/mjg/Safari-Shared-Links-to-OPML).
> The GitHub repository is a read-only mirror. Please open issues and submit contributions there.

This is an XSLT script to convert macOS Safari Shared Links feeds to an OPML file, suitable for import to other feed readers.

In addition to the plain XSLT, I've created a ZIPped app bundle created with [Platypus](http://sveinbjorn.org/platypus/) that will run it for you from Finder. You can find it on the [project release page](https://forgejo.phoenixtrap.com/mjg/Safari-Shared-Links-to-OPML/releases/latest).
